# How to Contribute

This repository is a fork of [bitwarden/clients](https://github.com/bitwarden/clients) that builds
the Black Mask privacy product on top of it (see [`docs/black-mask/`](docs/black-mask/) for the
Black Mask-specific engineering docs). For the underlying client codebase — build instructions,
recommended tooling, and code style — Bitwarden's upstream [Contributing Guidelines](https://contributing.bitwarden.com/contributing/) and [Contributing Documentation](https://contributing.bitwarden.com/) still apply and are the best starting point, since this fork inherits its build tooling and conventions largely unchanged.

Repo-specific rules (encryption boundaries, mono-repo placement, Tailwind conventions, etc.) live in
[`.claude/CLAUDE.md`](.claude/CLAUDE.md).
